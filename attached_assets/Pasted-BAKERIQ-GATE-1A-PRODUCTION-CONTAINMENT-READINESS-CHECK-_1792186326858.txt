BAKERIQ — GATE 1A
PRODUCTION CONTAINMENT READINESS CHECK

BACKGROUND

The following security changes have been implemented
and tested in the workspace:

1. Stripe Connect webhook authentication.
2. Fail-closed containment of the unauthorized
   /api/subscription/webhook-update endpoint.

All 38 tests pass.

NOTHING HAS BEEN PUBLISHED.

The legacy subscription endpoint now returns 503
without reading or modifying business records.

However, the authoritative Stripe-to-BakerIQ
subscription synchronization mechanism remains
incomplete.

OBJECTIVE

Determine whether we can safely publish the existing
security containment immediately, or whether a
replacement subscription synchronization path must
be deployed at the same time.

THIS IS A READ-ONLY PRODUCTION READINESS CHECK.

Do not modify production records, subscriptions,
Stripe settings, or application code.

Do not publish automatically.

1. INSPECT CURRENT SUBSCRIPTION DEPENDENCIES
------------------------------------------

Determine whether current subscriptions rely on
/api/subscription/webhook-update.

Inspect available application logs and integration
configuration for calls to this exact endpoint.

Report:

- Whether recent legitimate requests are visible.
- When the endpoint was last invoked, if known.
- Whether any identifiable internal service uses it.
- Whether the evidence is sufficient to conclude
  it can be disabled without disrupting subscribers.

Do not log or display secrets or customer PII.

Absence of visible requests is not proof that no
external caller exists.

------------------------------------------
2. VERIFY CURRENT SUBSCRIPTION CONSISTENCY
------------------------------------------

Perform a read-only comparison of:

- Active Stripe subscriptions.

- BakerIQ bakers.plan records.

- Relevant cancellation/past-due states.
- Trial and gifted-plan overrides.

Use redacted internal identifiers in the report.

Do not change account plans.

Do not assume that a local plan mismatch always
indicates an error without examining trial,
gifted-plan, and billing rules.

------------------------------------------
3. AFFILIATE AND REFERRAL DEPENDENCIES
------------------------------------------

- Legitimate affiliate commission awards.

Identify which events currently trigger these
operations and whether any other verified pathway
handles them.

Do not modify commission or referral records.
